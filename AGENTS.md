# Repository instructions

Read [Documentation.md](Documentation.md), especially
[Keeping settings changes documented](Documentation.md#keeping-settings-changes-documented).
For every settings commit, update its Change log with actual changes, usage,
verification and restore notes. Keep all user documentation in that one file.
Use codex/ work branches, preserve plugin locks and remote history, and keep
private state/credentials out of commits. Never move published checkpoint tags.
